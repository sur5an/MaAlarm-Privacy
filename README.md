# MaAlarm support

This public repository contains MaAlarm's privacy policy and support information.

MaAlarm is a privacy-first iPhone and iPad app that helps people keep ahead of important document and premium-payment dates. The app stores records locally on the device and does not use a backend, analytics, advertising, or automatic cloud sync.

- [Privacy policy](PRIVACY_POLICY.md)
- Support and feedback: feedback.maalarm.com@gmail.com

This repository intentionally contains no application source code, backup files, documents, screenshots containing personal information, or credentials.
