# MaAlarm privacy policy

Effective date: September 1, 2026

MaAlarm helps users track expiry and premium-payment dates for personal documents. Privacy is a core design principle.

## Data stored by the app

MaAlarm stores the document information that a user enters or accepts from an on-device scan, including owner name, document type, description, relevant dates, reminder settings, and any locally saved owner names. This information is stored only in the app's local device database.

The app does not require an account and does not operate a backend service. MaAlarm does not upload, sell, rent, share, or use document information for advertising, tracking, or analytics.

## Document scanning

When a user chooses to scan a document, Apple system scanning and on-device text recognition are used to suggest fields. Document images and recognized text are not uploaded to MaAlarm servers and are not retained by the app after the user finishes the scan flow. Users should review scan suggestions before saving.

## Notifications

If a user grants permission, MaAlarm schedules local notifications on that device to remind the user about upcoming or overdue dates. Notification content is created from locally stored information and is not sent through a MaAlarm server.

## Export and restore

Users can export their records to a CSV file using the iOS share sheet and later restore from a chosen CSV file. Exported files can contain personal document-related information. Users are responsible for choosing a secure destination and deleting copies they no longer need. MaAlarm does not automatically upload backups to a cloud service.

## Feedback

If a user chooses **Send feedback or report a problem** from the Privacy & data screen, MaAlarm opens Apple's standard Mail composition screen with a support recipient prefilled. The user can review, edit, cancel, or send that message. MaAlarm does not read the message content or send it itself; if the user sends it, the message is delivered by the user's Mail app and may include the sender's email address and any information the user voluntarily writes. Do not include document numbers, card details, or other sensitive information in feedback.

## Changes to this policy

If MaAlarm changes how it handles information, this policy will be updated before or when that change is released.
